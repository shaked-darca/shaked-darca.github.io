# שקד דרכא עמק המעיינות – אתר ואפליקציה

אתר סטטי שאפשר להתקין כאפליקציה (PWA) בטלפון ובמחשב.

## מה יש כאן
- `index.html` – האתר כולו. הנתונים (אירועים, שוקדים, תמונות) נמצאים בתוך הקובץ, בבלוק `<script type="application/json" id="data">`.
- `manifest.webmanifest`, `sw.js`, `icons/` – מה שהופך את האתר לאפליקציה: אייקון, פתיחה במסך מלא ועבודה גם בלי אינטרנט.
- `media/` – תמונות, עמודי שוקדים וקובצי PDF.
- `scripts/sync_calendars.py` ו־`.github/workflows/sync-calendars.yml` – משיכת האירועים מיומני Google של בית הספר כל שעה (06:00–22:00), אוטומטית, דרך GitHub Actions.

## עדכונים
- **אירועים:** מוסיפים ומשנים רק ביומני Google. האתר מתעדכן לבד בתוך שעה. אפשר להריץ ידנית: Actions ← "סנכרון יומנים" ← Run workflow.
- **שוקדים:** מעלים PDF לתיקיית "שוקדים" בדרייב. משימה מתוזמנת מפרסמת אותו באתר.

## דומיין
כשיהיה דומיין: מוסיפים קובץ `CNAME` עם שם הדומיין, ומגדירים אצל רשם הדומיין רשומות DNS לפי ההוראות של GitHub Pages.
